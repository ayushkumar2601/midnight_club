# Midnight Hold’em

> **Bluff like nobody’s watching.**

A cinematic real-time multiplayer poker experience built around the concept of confidential smart contracts and provably fair gameplay using Midnight.

---

# ♠ What is Midnight Hold’em?

Midnight Hold’em is a cyberpunk-inspired multiplayer Texas Hold’em platform where:

* player hands remain private,
* gameplay stays fair and verifiable,
* and bluffing actually matters.

Traditional blockchains expose all game data publicly, which breaks competitive games like poker.

Using the ideas behind Midnight, Midnight Hold’em explores how confidential smart contracts can power a new generation of multiplayer web3 games with hidden game state and cryptographic fairness.

# 🧠 Why Midnight?

Midnight enables something traditional blockchains struggle with:

## Confidential Gameplay

Poker requires:

* hidden cards,
* secret strategy,
* bluffing,
* and private player state.

Public blockchains expose all information, which destroys competitive integrity.

Midnight Hold’em demonstrates how confidential smart contracts could allow:

* private game logic,
* hidden information,
* and trustless multiplayer fairness

to coexist in a fully playable gaming experience.
